Machine load vs. agent activity

    
Pearson r between each machine metric and hourly agent activity over the selected range (machine metrics are machine-wide; project filter applies to the activity side). Warm = rises with activity.

    


Lagged correlation activity 

    
r between hourly activity at t and each machine metric at t + lag. Positive lag = the machine reacts after the agents; negative = load leads (e.g. builds that precede prompts). Outlined cell = strongest per metric.
